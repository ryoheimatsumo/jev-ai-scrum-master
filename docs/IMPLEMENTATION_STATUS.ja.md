## 実装済み

JUnit・JSON結果、証拠の鮮度、修正回数上限、完了条件、改善提案を扱います。
Jevには準備・手順・関連情報・証拠についての助言と、永続的な助言キャッシュがあります。
Jev単独で完了を承認することはできません。

# Pull request guidance

[日本語](PULL_REQUEST.ja.md)

The old initial-publication draft is no longer current guidance. For new work, describe the
change, its tests, limitations, generated assets, and English/Japanese documentation updates.
Use [Contributing](../CONTRIBUTING.md). Do not copy past test counts into a new PR as fresh results.
A merge, GitHub release, registry publication, and official directory listing are separate actions.

# 残作業

[English](BACKLOG.md)

以下は計画であり、利用可能な機能一覧ではありません。[現在の実装状況](IMPLEMENTATION_STATUS.ja.md)。

## 本番βより先に改善する信頼性

1. 検証済みSDK・ホストの組み合わせを固定し、許可された実Jevでスキーマ、タイムアウト、再試行、使用量を確認します。
   要求モデルと実モデルのIDを保持し、不明な数量は不明と記録します。
2. 隔離された読み取り専用のCodex・Claudeレビューを追加します。厳格な結果スキーマ、再帰MCPの防止、
   制限した認証情報、実ホスト試験を用意し、人間への代替経路を残します。
3. ジョブの所有期限とクラッシュ復旧を実装します。残存プロセス、PID再利用、待機・実行中ジョブを扱い、
   未完の副作用を承認なしに再実行しません。
4. 依存関係・環境の指紋、外部テストの有効期限、証拠削除時の処理を改善します。
5. プロセス間でモデル予算を原子的に予約し、移行、保持期間、中断時の診断を管理します。
6. 子タスクの統合、保護assertionの緩和レビューを含むP-01〜P-28の目標条件を完成させます。
   入力内の指示注入と、ファイルの同時変更に対するテストを追加します。

## 任意のJev実験

証拠の行ID選択と独立した十分性確認、隔離環境での受け入れ基準に対応するミューテーション検証、
複数の計画候補、根拠に沿ったLLM出力の意味評価、履歴と未使用データを使った質問改善が対象です。
これらを理由に、必須作業を黙って増やしたり、現行の承認・上限・完了条件を緩めたりしません。

## 価値の測定

通常のエージェント、同じ開発ループでJevなし、Jevありを、同じ予算と課題で比較します。
誤DONE、受け入れ可能な成果、総費用・時間・人間の作業、不要な介入、回帰、再発を測定します。
全試行とスキップしたチェックを含め、文字数だけで節約を主張したり、成功例だけを集計したりしません。

## 文書の保守

日英、現状、導入コマンド、安全性の説明を揃えます。過去の仕様・レポートは履歴と分かるようにし、
新しい結果が得られたかのように書き換えません。

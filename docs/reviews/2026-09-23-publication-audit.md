# 公開内容の監査 — 2026-09-23

## 対象と方法

対象は `ryoheimatsumo/jev-ai-scrum-master` の公開main、commit
`fbf81592248216bcc7e1fc2f4f81d3773b96e4cb`。
公開ファイル122件、同梱wheelの34エントリー、公開ブランチの到達可能な6コミットの
メタデータと変更範囲を確認した。ブランチはmainとマージ済みdocsブランチ、タグは未作成だった。

全ファイルを既知の認証情報形式・秘密ファイル名・メール・ローカルパス等で走査し、
README、導入案内、Skill、実行/外部送信/承認処理、公開補助コード、CI、ライセンス、
検証記録の意味を確認した。これは全コード経路の安全性を証明する監査ではない。

ローカルにある初回公開アーカイブはGit tree
`b53b3b58ec39b1a8ff7d320c437610af0333fb0f`と一致した。
GitHubから確認したPR #1の4文書のblob IDで置き換えたtreeは現行mainの
`18807f47ef7ad0c8a97ca4294e3edc65428b4a6a`と一致し、残りのファイルの同一性を確認した。
ローカルGit cloneはDNSエラーだったため、GitHubコネクターのライブ情報とこの照合を使用した。

## 確認結果

| 観点 | 結果 |
| --- | --- |
| 実キー・認証トークン・秘密鍵 | 選択したパターンと目視確認で、実情報と疑われるものは検出されなかった。実際の認証を試す検査はしていない |
| 個人/顧客情報 | 実メール・顧客データ・住所に相当する記録は見つからなかった。コミットメールはGitHub noreply形式 |
| ローカル環境情報 | 検証記録7ファイルに機械固有パスや一時ホスト名が残っていた。既知のユーザー資格情報ではない |
| 旧案内 | QuickstartのOWNERプレースホルダー、公開前の説明、内部用PR原稿が残っていた |
| 表現と信頼境界 | local-first、installerの上書き保護、検証済み範囲の説明をより明確にする必要があった |
| 公式との関係 | 独立プロジェクトである説明は仕様にあるが、公開READMEにも明示する必要があった |
| 配布ライセンス | リポジトリと同梱wheelにApache-2.0のライセンス文があり、wheelの自作コード/Skillはソースと一致 |
| wheelの説明 | 固定a3 wheelのMETADATAは公開前READMEを含む。現行ユーザー案内と区別し、次版で更新する |

実キー流出を示す根拠は確認できなかったが、「秘密が絶対にない」「脆弱性がない」とは判断しない。

## 今回の変更

- READMEとQuickstartを利用者向けに整理し、正しい公開元へ統一。
- 独立プロジェクト、実験的alpha、人間の代替レビューが必要なことを明示。
- ローカル保存と、ホストAI/Jev/インストーラーの外部送信を区別。
- 第一者CLIのinstaller保護を、第三者npx/marketplaceへ拡大解釈しないよう修正。
- 内部用の過去PR原稿を、一般的なPRテンプレートへ置換。
- 検証記録の公開用コピーから機械固有パス・ホスト名だけを匿名化。結果、件数、skip、時間、版は維持。
- 過去の検証時点と現在の公開/CI状態を分離。履歴の未公開/未実行値は成功に書き換えていない。
- オフラインの公開内容チェックと回帰テスト15件を追加。
- CI checkoutの認証情報保持を無効化。権限は引き続きcontents:read。
- ローカル配布validatorが未確認の公開状態をfalseと断定しないよう、null/not-checkedに変更。

ランタイム、Jevの判定内容、承認、PASS/DONE条件は変更していない。
a3 wheelはハッシュとソースの一致を確認して保持し、同じ版を黙って作り直していない。
初回公開manifestは当時の固定記録であり、現行main用の整合性証明ではないと文書化した。

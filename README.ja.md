# Jev AI Scrum Master

[English](README.md) | **日本語**

**完成条件を決め、証拠で確かめ、次の開発に生かす。**

普段使っているコーディングエージェントに追加する、ローカルCLI付きのSkillです。
計画と実装はエージェントが担当し、Coreが承認済みの検証、証拠の鮮度、タスクの完了条件を管理します。
**MCPの設定は必須ではありません。**

**実験的α版 — `0.1.0a4`。** 信頼できるローカルリポジトリが対象です。
実際のコーディングエージェントとの互換性や、品質・速度・費用・トークン使用量の改善は、
本プロジェクトではまだ実証していません。standardタスクには現在、人間のレビューが必要です。
[現在の実装状況](docs/IMPLEMENTATION_STATUS.ja.md)を参照してください。

## できること

| 段階 | 支援内容 |
|---|---|
| 計画 | 目指す成果、受け入れ基準、検証方法、未確定事項を明確にします。 |
| 実装 | 既存のコーディングエージェントが、承認済みの範囲で実装します。 |
| 検証 | 登録済みのチェックを実行し、結果を対象コードと基準にひもづけます。 |
| 完了 | 現在の証拠と必要な承認を確認してから、DONEを記録します。 |
| 改善 | 類似タスクに生かす改善案を残します。採用には人間の承認が必要です。 |

例えば「項目を変更して保存する」タスクでは、画面の変化だけでなく、保存後に新しく取得した
データも確認します。「画面が変わった」という申告だけを、保存成功の証拠にはしません。
この違いを管理するツールであり、不具合が存在しないことを証明するものではありません。

大きな変更では、依頼全体のユーザーストーリーと受け入れ基準を読みやすい計画カードにまとめます。
現在のカードをチャットで明示的に承認すると、エージェントがハッシュに結び付けた計画承認を記録し、
価値ごとの小さな単位で実装・検証を進めます。範囲や基準の重要な変更には再確認が必要です。
standardタスクの最終的な代替レビューは、引き続き人間が行います。

## インストール

開発対象プロジェクトのGitルートで実行します。

```bash
npx skills add ryoheimatsumo/jev-ai-scrum-master --skill jev-scrum-master
```

導入先を対話的に選ぶか、`-a codex`、`-a claude-code`、`-a cursor`などを追加します。
配置対象として選べることと、本製品の実機動作を検証済みであることは別です。
[他のエージェント・マーケットプレイス・更新方法](docs/DISTRIBUTION.ja.md)。

Claude Codeのリポジトリマーケットプレイスを使う場合：

```text
/plugin marketplace add ryoheimatsumo/jev-ai-scrum-master
/plugin install jev-ai-scrum-master@jev-dev-tools
```

1つのホストでは1つの導入経路を使ってください。これは独立したリポジトリマーケットプレイスであり、
公式ディレクトリへの掲載や推奨を意味しません。

## 使い始める

エージェントに次のように依頼します。

> jev-scrum-masterを、このリポジトリで使えるようにセットアップして。

セットアップ内容を確認し、実際のテストコマンドを登録してから、開発タスクを依頼します。
Skillには専用CLI環境を準備するランチャーが含まれます。ダウンロードには同意が必要です。
プロジェクトのテスト依存関係の準備と、タスクの承認は別に行います。

**必要な環境：** CoreにはGitとPython 3.12以上、`npx`にはNode/npmが必要です。
Linuxはローカル検証済み、macOSは未検証、ネイティブWindowsはこのα版の対象外です。

Jevは**初期状態では無効**です。利用には任意SDK、環境変数`TYPESAFE_API_KEY`、確認済みの設定が必要です。
認証情報をチャットへ貼ったり、Gitに登録したりしないでください。
[クイックスタート](docs/QUICKSTART.ja.md) · [Jevの設定と使い方](docs/JEV.ja.md)。

## Jevの役割

Jevは計画の不足、次に使う調査手順、関連情報の選別、受け入れ基準と証拠の関係について、限定的な助言を行います。
実装、テスト合格、権限付与、完了の承認を担うものではありません。
判断不能やAPI障害でも、必要なレビューは免除しません。
ホストがこの手順を呼び出す必要があり、Skillは常時監視する仕組みではありません。

## 安全性と制限

登録したテストはコードを実行します。作業用コピーと環境変数の制限は、**OSやネットワークのサンドボックスではありません**。
信頼できるリポジトリと本番以外のデータを使ってください。同じOSユーザーのプロセスは、コピー外のファイルへ
アクセスしたり、ローカル状態を変更したりできます。[セキュリティモデル](SECURITY.ja.md)。

DONEは、このツール内の現行タスク契約に対する状態です。正しさの保証、独立認証、マージ、デプロイ、Jiraの完了を
意味しません。自動の独立AIレビュー、クラッシュ復旧、強制フック、ミューテーションテストは未実装です。

Coreは外部テレメトリーを自動送信しません。ただし、コーディングホスト、インストーラー、パッケージ配布元、
有効にしたJev APIには、それぞれ通信と利用規定があります。第三者のSkillsインストーラーのテレメトリーを
停止する場合は`DISABLE_TELEMETRY=1`を設定します。[データの扱い](SECURITY.ja.md)。
